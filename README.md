Unit 4 - Terraform and Ansible

Overview

This project focuses on automating cloud infrastructure and deploying a web application using AWS, Terraform, Ansible, Docker, Flask, and Nginx.

What I Learned

- Creating and managing cloud infrastructure using Terraform.
- Automating server configuration with Ansible.
- Building a Flask application using Docker.
- Deploying a web application and exposing it through Nginx.
- Organizing configuration files, inventory, and deployment settings.

What I Did

- Prepared Terraform configuration for AWS infrastructure.
- Created Ansible inventory files, playbooks, and roles.
- Developed a Dockerized student academic application using Flask.
- Configured the application and web server for deployment.
- Organized the project files for easier management.

Project Structure

Unit-4/
├── terraform/    # Terraform configuration files
├── ansible/      # Inventory, playbooks, and roles
└── app/          # Flask application, Dockerfile, and requirements

Technologies Used

- AWS - Cloud infrastructure
- Terraform - Infrastructure as Code
- Ansible - Server configuration automation
- Docker - Application containerization
- Flask - Web application framework
- Nginx - Web server and application access

Security Note

Review all configuration files and credentials before deployment. Never commit private keys, AWS access keys, secret keys, or other sensitive information to a public repository.
